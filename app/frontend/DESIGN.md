# Atoms-Lite 设计规范

## Direction & Layout
- 定位：开发者向 AI 网页生成工作台，气质冷静、精密、工具感（参考 Linear / v0）。第一屏的核心视觉：左侧智能体控制台与右侧“浮在深色画布上的发光沙箱”并置。
- 布局：桌面 ≥1024px 为双栏，左栏固定 420px，右栏自适应；<1024px 顶部分段切换“对话 / 预览”单栏展示。无横向滚动，全高 100dvh，各面板内部滚动。
- Do：紫色只用于主操作、选中态、流式光标；电光蓝仅用于状态/链接点缀。Don't：大面积渐变背景、发光卡片边框、Orbitron 等科技字体。

## Tokens
- 颜色：背景 #0B0B0F；面板 #111116；抬升面 #17171E；边框 #24242E；主文字 #EDEDF2；次文字 #9A9AAB；弱文字 #62626F；主色紫 #8B5CF6（hover #7C4DEB）；电光蓝 #38BDF8；成功 #34D399；警告 #FBBF24；错误 #F87171。
- 字体：Manrope（界面，400/500/600/700），JetBrains Mono（代码、数值）。标题 15px/600，正文 13.5px/1.6，说明 12px，代码 12.5px/1.65。
- 间距 4 的倍数；圆角：按钮/输入 8px，卡片 12px，预览画框 14px；图标按钮 32px 方形圆角 8px。
- 层级：以 1px 边框 #24242E 区分，浮层阴影 0 20px 50px -12px rgba(0,0,0,.6)。

## Shared Patterns & States
- 图标按钮 / 主按钮：hover 背景提亮 + 150ms ease-out，active scale(.96)，禁用 40% 透明。
- 消息气泡：用户消息右对齐紫色底；AI 消息左对齐面板底，附版本徽标。生成中显示闪烁光标。
- 预览加载：骨架屏 + 脉冲；状态栏显示加载状态、延迟、错误数，可展开控制台。
- 可访问性：图标按钮带 aria-label/title，焦点环 2px #8B5CF6。

## Media
- 纯操作界面，不需要图片；Logo 采用 CSS 几何图形。
